## ✅ 기능 요구 사항

### 1️⃣ 프로그램 입력

- [x] 주어진 횟수 동안 n 대의 자동차는 전진 또는 멈출 수 있다.
- [x] 각 자동차의 이름은 `,` 를 기준으로 구분되며, "5자 이하만 가능하다."
- [x] 시도할 횟수를 입력 받으며 해당 횟수 동안 자동차는 전진 또는 정지 한다.

---

### 2️⃣ 동작 매커니즘 및 출력

- [x] 0에서 9사이의 무작위 값을 구한 후 해당 값이 4 이상인 경우 전진한다.
- [x] 전진하는 자동차를 출력할 때 자동차 이름을 같이 출력한다.
- [x] 게임이 완료되면 우승자를 출력하며 한 명 이상일 수 있다. (`,` 로 구분)

---

### 3️⃣ 예외 처리 기능

- [x] 입력이 잘못된 형식일 경우 `IllegalArgumentException`을 발생시킨다.
- [x] 예외 발생 시 애플리케이션을 즉시 종료한다.
- [x] 5글자를 넘는 자동차 이름이 입력된 경우 예외처리를 수행한다.

---

### 입출력 예시

#### 입력

* 경주할 자동차 이름 (이름은 쉼표 `,` 기준으로 구분)

```
pobi,woni,jun
```

* 시도할 횟수

```
5
```

<br/>

#### 출력

* 차수별 실행 결과

```
pobi : --
woni : ----
jun : --
```

* 단독 우승자 안내 문구

```
최종 우승자 : pobi
```

* 공동 우승자 안내 문구

```
최종 우승자 : pobi, jun
```

<br/>

#### 실행 결과 예시

